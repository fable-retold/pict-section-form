Does solver-driven visibility survive a re-render?

  1. On load, Average Gradation is hidden — Show Gradation is unchecked and the section solver hid it.
  2. Rename any product in Aggregate Products and tab out. That changes a generated column label, so every section whose columns come from Products re-renders.
  3. For the group equivalent: tick Show Gradation so the section is visible, leave Show Notes unchecked, and rename a product again — the hidden Gradation Notes group inside it behaves the same way.

Broken: Average Gradation (or the Gradation Notes group) reappears with its box still unchecked.
Fixed: it stays hidden, and its column headers still pick up the new product name — check the box to confirm the labels updated underneath.
